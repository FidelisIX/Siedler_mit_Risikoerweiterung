# Datenbranch `statistik`

Wird vom Archipel-Server beschrieben, nicht von Hand bearbeiten.

- `spiele/JJJJ-MM.jsonl` – eine Zeile pro beendeter Partie (Statistik)
- `raeume/<CODE>.json` – Raumsicherungen beim Neustart (werden nach dem Wiederherstellen gelöscht)

Dieser Branch darf nie der Deploy-Branch sein. Render deployt nur `main`.
